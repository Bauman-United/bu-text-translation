# Как получить токен VK для бота

Рабочий способ (проверен 2026-09): бессрочный токен через официальное
standalone-приложение VK (Kate Mobile). Такие токены не привязаны к IP и не
истекают, поэтому подходят для бота на сервере и не требуют ежедневной замены.

## Основной способ: бессрочный токен (Kate Mobile)

1. Открой в обычном браузере (никаких прокси не нужно):

   ```
   https://oauth.vk.com/authorize?client_id=2685278&scope=video,wall,offline&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token&v=5.199
   ```

   `client_id=2685278` — это Kate Mobile; `offline` даёт «доступ в любое
   время», из-за него токен бессрочный.

2. Нажми «Разрешить». Тебя перекинет на пустую страницу `blank.html`.

3. Скопируй **весь адрес** из адресной строки и пришли боту:

   ```
   /set_vk_token <вставь адрес>
   ```

Бот проверит токен через `users.get`, сохранит его в `data/vk_token.json` и
подхватит без перезапуска. В ответе будет «срок неизвестен» — это нормально:
`expires_in=0` в адресе редиректа означает бессрочный токен.

### Когда токен умирает

Токен слетает при смене пароля VK, отзыве доступа приложению
(vk.com/settings?act=apps) или если VK сам его отзовёт. Лечится повторением
трёх шагов выше.

### Почему именно так

* Токены implicit flow **новых** приложений VK ID привязываются к IP, с
  которого пройдена авторизация: токен из домашнего браузера сервер использовать
  не может — VK отвечает ошибкой 5 `access_token was given to another ip
  address`. У старых standalone-приложений привязки нет.
* Своё приложение такого типа сейчас не создать: кабинет VK ID требует данные
  ИП/юрлица, а `offline` для новых приложений вообще убран (токены живут 24 ч).
* Авторизация через client_id официального приложения — серая зона правил VK,
  но для личного бота, читающего стены и комментарии от своего же аккаунта,
  способ массовый и живёт годами.

## Запасные варианты

Если способ выше перестанет работать:

1. **Своё приложение + code flow (полностью «белый», с автообновлением).**
   Зарегистрировать приложение в кабинете VK ID (потребуются данные ИП),
   платформа «Web», прописать «Доверенный Redirect URL» — страница может ничего
   не отдавать, важен только адрес. В `.env` задать `VK_APP_ID` нового
   приложения и `VK_REDIRECT_URI`. После этого `/set_vk_token` сам переключится
   на code+PKCE: сервер обменивает код на пару access+refresh, токен выпускается
   на IP сервера, бот продлевает его автоматически.

2. **Своё приложение + implicit flow через прокси сервера.** Без
   `VK_REDIRECT_URI` бот выдаёт ссылку implicit flow; токен привяжется к IP,
   с которого открыта ссылка, поэтому открывать её надо через прокси сервера:
   `ssh -D 1080 -N user@сервер`, в браузере SOCKS5 `localhost:1080`. Токен
   живёт 24 часа, менять вручную.

## Примечания

* Токены сообществ и сервисные ключи не подходят: `wall.get` и
  `video.getComments` отвечают на них ошибкой 27.
* `data/` должен быть примонтированным volume в Docker — там лежит токен.
* Watchdog напоминает о замене только когда токен со сроком истекает до
  ближайшей игры; про бессрочные и автообновляемые токены он молчит.
